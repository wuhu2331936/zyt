# 智药通 — 演示视频脚本大纲（5–8 分钟）

## 1. 开场（30s）
- 自我介绍 + 作品名称
- 痛点：老年人看不懂药盒、记不住用法、容易忘服错服

## 2. 核心功能演示（4–6 分钟）

### 2.1 拍照识药（1min）
- 上传药盒照片 → AI 识别药品名、规格、用法用量
- 高亮「老年人友好大字体」展示

### 2.2 药物详情 + 相互作用（1.5min）
- 添加多种药品到清单
- 演示"华法林 + 阿司匹林"相互作用风险提示
- 强调基于 RAG 检索药品说明书

### 2.3 服药提醒（1min）
- 设置早 8:00 / 晚 8:00 两个提醒
- 触发提醒时播放 Edge-TTS 语音

### 2.4 语音问答（1.5min）
- 按住说话："高血压能吃布洛芬吗？"
- 实时转写 + 文字回答 + 语音播报

## 3. 技术架构（30s）
- 简述：Vue3 PWA + FastAPI + 通义千问 VL + DeepSeek + ChromaDB

## 4. 总结（30s）
- 价值：让老年人独立、安全用药
- 未来：接入更多药品说明书 / 家属端
