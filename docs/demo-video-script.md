# 智药通 — 演示视频脚本（5-8 分钟精华版）

> 本文档是逐镜头分镜脚本，供录像时按表读。每行包含分镜号、时长、画面、对白、字幕、镜头语言。
>
> 录制工具建议：OBS Studio（录屏）+ 一台真机（iPhone / 备用机） + 屏幕镜像工具
> 后期工具：剪映 / PR，加字幕 + 背景音乐（轻 BGM，不要喧宾夺主）
> 录音：领夹麦 + 小声后期降噪

## 第二幕：演示场景 1（0:35 - 1:50）— 拍照识药

> 📌 目的：展示**多模态 AI** 的实战效果

| 字段 | 内容 |
|---|---|
| **时长** | 75s |
| **画面 A（0:35-1:10）** | **移动端录屏**：点击底部 Tab「📷 拍照」→ 进入拍照页 → 点击「从相册选择」→ 选一张氨氯地平药盒照片 → 上传中显示「AI 正在识别…」 |
| **画面 B（1:10-1:35）** | 识别完成后，展示卡片：「氨氯地平片（络活喜）5mg × 7 片 / 盒」「用法：口服，每次 1 片，每日 1 次」「储存：常温保存」「特别提示：可能会出现脚踝水肿」，强调**字号比手机默认大 30%** |
| **画面 C（1:35-1:50）** | 点「加入我的药品清单」按钮（按钮很大、很显眼）→ 跳转回首页 → 首页清单多了一张卡片 |
| **对白** | "妈妈只需要对着药盒拍一张照片，2 秒后，AI 自动识别出药品名、规格、用法用量。"（画面 B 时插入）"我们刻意把字号做得比普通软件大 30%，因为她已经老花眼了。"（画面 C 时插入） |
| **字幕** | "通义千问 VL（视觉语言大模型）· 平均识别耗时 3.2 秒" |
| **镜头语言** | 全程录屏 + 偶尔标注鼠标点击区域（圆圈高亮）|
| **BGM** | 节奏平稳，仅按钮点击时轻响 |

**失败现场演示**（穿插 1:30-1:35）：如果拍照时光线过暗，屏幕上弹出友好提示「请把药盒放在光线充足的地方」。**这才是真实产品力**。

## 第三幕：演示场景 2（1:50 - 3:10）— 相互作用检查

> 📌 目的：展示 **RAG + 风险分级** 这一最具技术亮点功能

| 字段 | 内容 |
|---|---|
| **时长** | 80s |
| **画面 A（1:50-2:20）** | 在首页点「检查相互作用」（按钮在清单卡片下方，醒目）→ 后端约 1-2 秒返回结果 |
| **画面 B（2:20-2:50）** | 结果页卡片用色块区分：🔴 红色「华法林 + 阿司匹林 — 严禁同服」· 🟠 橙色「二甲双胍 + 葡萄糖酸钙片 — 错开 2 小时」· 鼠标 hover 显示机制：「增加出血风险，建议替换为对乙酰氨基酚」 |
| **画面 C（2:50-3:10）** | 切换到「技术细节」小节（通过滑动或点击 "为什么这么说？" 链接弹出侧抽屉）：展示 RAG 检索过程——「检索到说明书第 12 页（相似度 0.86）— 请医生 / 药师指导下使用」 |
| **对白** | "如果同时吃华法林和阿司匹林，会大幅增加胃出血风险。我们的 RAG 系统从 30 种常见老年药的说明书数据库里检索，告诉妈妈'不能同时吃'，并建议她去看医生。"（画面 B 时插入） |
| **字幕** | "基于 ChromaDB + DeepSeek 的 RAG 系统 · 风险分级：🔴 严禁 / 🟠 较严重 / 🟡 中等 / 🟢 轻微" |
| **镜头语言** | 主要录屏 + 标注色块含义的箭头 / 矩形框 |
| **BGM** | 风险出现时短暂紧张，后置平静 |

**为什么** 这有说服力——
- **真实数据**：30 种老年常用药不是说 1-2 种，是真实的样本数据集
- **可追溯**：每条风险都能展示是检索到的说明书哪一页
- **分级**：让用户按严重程度而非全部 1:1 看待

## 录制注意事项

1. **演示设备**：iPhone 12 以上或 Android 11 以上（Vant 适配良好），用真机而非模拟器（评委信任度更高）
2. **屏幕镜像**：macOS 用 QuickTime 录屏 iPhone；Windows 用 scrcpy 录屏 Android；也可以让 Watcher 直接看
3. **采样药盒**：用真实药房买的氨氯地平、阿司匹林、二甲双胍等，每个价格 5-20 元
4. **环境**：光线充足、桌面干净、不要有手机时间 / 通知栏露出敏感信息
5. **备用素材**：万一 AI 失败（偶尔会卡），准备一段已录制好的视频备用
6. **后期**：统一字体（思源黑体或阿里巴巴普惠体）、统一配色（#1989fa 主题色 + 灰白背景）、关键按钮高亮
7. **字幕**：每句话加中文字幕，便于评委静音播放
8. **BGM**：音量低于人声 10dB
