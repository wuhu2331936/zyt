# 智药通 — 产品需求文档（PRD）

> 写作目的：把 MVP 阶段的所有产品决策记录下来，方便未来迭代时复用上下文，
> 也是**评委了解项目初衷**的第一手材料。

---

## 1. 项目背景

### 1.1 用户画像

| 维度 | 描述 |
|---|---|
| 年龄 | 60-80 岁 |
| 视力 | 多有老花眼 / 白内障 |
| 学历 | 平均初中以下 |
| 设备 | 多为千元安卓机，少部分 iPhone |
| 居住 | 80% 与家人同住，20% 独居 |
| 健康 | 73% 患 1 种以上慢病；平均每天吃 5 种药 |

### 1.2 用户痛点（自调研 30 位老人）

| 痛点 | 频次 | 严重度 |
|---|---|---|
| 药盒说明书字太小，看不清 | 87% | ⭐⭐⭐⭐⭐ |
| 同时吃 3-5 种药，不知能不能一起 | 60% | ⭐⭐⭐⭐⭐ |
| 忘记按时服药 | 53% | ⭐⭐⭐⭐ |
| 想问医生但儿女忙 | 47% | ⭐⭐⭐ |
| 买药重复（同一成分不同商品名）| 33% | ⭐⭐⭐ |

### 1.3 现有方案分析

| 方案 | 不足 |
|---|---|
| ⼿机相机 + 翻译 App | 操作步骤多、英文翻译差 |
| 微信问医生 | 24h 回复、上传图片压缩 |
| ⼤医院 App | 需医保卡、字体更小 |
| 药盒 AI（仅有识别无交互）| 数据留存差、不能查相互作用 |

**机会**：把「拍照识药 + 相互作用检查 + 语音提醒 + 语音问答」四件事做成一个 PWA，免安装、跨平台、离线可用。

---

## 2. 产品定义

### 2.1 一句话定位

> 用 AI 让每位老人独立、安全、按时服药。

### 2.2 核心价值主张

- **看得清** — AI 自动识别药品信息并放大字号
- **吃得对** — 主动告诉老人"这俩药不能一起吃"
- **忘不掉** — 到点震动 + 语音播报
- **问得到** — 24h 私人用药顾问

### 2.3 北极星指标

> 月活老人数 × 平均每日 App 打开次数 × 提醒准时服药率

## 3. 功能范围（Scope）

### 3.1 MVP（已交付）

| # | 功能 | 用户故事 |
|---|---|---|
| F1 | 拍照识药 | 作为老人，我拍照就能看到药品说明，不用翻小字说明书 |
| F2 | 用药清单 | 作为老人，我的常吃药品都在首页，一目了然 |
| F3 | 相互作用 | 作为老人，加入清单后能一键知道哪些药不能一起吃 |
| F4 | 服药提醒 | 作为老人，我不用记几号吃药，到点手机自动说给我听 |
| F5 | 语音问答 | 作为老人，我可以问"这个药饭前饭后吃"，AI 直接回答 |

### 3.2 不做（未来可能做）

- 🔒 多账号 / 家人共享 — 当前 localStorage 单机
- 📈 长期服药趋势分析 — 缺健康数据输入
- 🩺 在线问医生 / 配药 — 需医疗资质
- 🏥 病历同步 — 隐私合规要求高
- ⌚ 手环 / 智能药盒硬件对接 — 周期长

## 4. 用户体验原则

### 4.1 适老化

| 维度 | 标准 |
|---|---|
| 字号 | ≥ 18px（默认 16px）|
| 按钮 | ≥ 48 × 48px（推荐 56×56）|
| 对比度 | AAA 级（white on #1989fa = 7.1:1）|
| 图标 | 必须配文字，不能单独用图标 |
| 操作步骤 | 主要功能 ≤ 2 次点击 |
| 错误提示 | 文案具体："请再靠近一点拍照"而非"未知错误" |

### 4.2 语音优先

- 所有功能都有语音交互备选
- 药品详情可一键 "🔊 朗读"
- 语音问答按住即可，松开自动识别

### 4.3 离线可用

- 已添加的药品清单：离线可看
- 已加载的详情页：离线可看
- AI 识药/问答/播报：在线时使用（无网络时明确提示）

## 5. 技术决策

### 5.1 为什么选这些技术

| 决策 | 选项 | 选定 | 原因 |
|---|---|---|---|
| 前端框架 | Vue/React/Svelte | **Vue3** | 国内社区资源多、Vant 移动端生态成熟、个人赛效率优先 |
| 移动端组件 | Vant/Vant Weapp/antd-mobile | **Vant** | Vue3 配套；按需引入包小 |
| PWA 方案 | @vue/cli-plugin-pwa / vite-plugin-pwa | **vite-plugin-pwa** | Vite 生态原生、零配置 |
| 后端框架 | Flask/Django/FastAPI | **FastAPI** | 异步 + 自动 OpenAPI + 性能强 |
| 识图模型 | 通义千问 VL / GPT-4V / Gemini | **通义千问 VL** | 中文药品包装识别率高 + 国内 API 稳定 + 价格低 |
| 对话模型 | GPT-4 / Claude / DeepSeek | **DeepSeek** | 1/10 价格 + 中文强 |
| 向量库 | Pinecone / Milvus / ChromaDB | **ChromaDB** | 本地部署零配置；个人赛够用 |
| Embedding | OpenAI / DashScope / BGE | **BAAI/bge-small-zh** | 完全免费 + 中文优化 + 体量小（180MB） |
| TTS | 讯飞 / 阿里云 TTS / Edge-TTS | **Edge-TTS** | 免费、质量高、不需 Key |

### 5.2 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| AI 识别错误 | 用户可能误服 | 风险页强制显示"以药品说明书为准" |
| 向量库太小 | RAG 漏召回 | 提供 LLM 兜底（内置医学知识） |
| 网络差 | 用户体验差 | PWA 离线 + Loading 占位 |
| 老人不会用 | 留存差 | 视频教程 + 文字 + 语音三重引导 |

> 做中国 2.6 亿老人的"随身 AI 药师"。
