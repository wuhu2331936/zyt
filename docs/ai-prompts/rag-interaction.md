# 💊 药物相互作用 RAG Prompt 快照

> 文件位置：`docs/ai-prompts/rag-interaction.md`
> 生成时间：阶段 4 完稿
> 适用接口：`POST /api/interaction/check`
> 模型：`deepseek-chat`（支持 `response_format={"type": "json_object"}`）
> 向量库：ChromaDB + BAAI/bge-small-zh

---

## 架构

```
用户药品列表
    ↓
拼接 Query（"药A、药B 之间是否存在药物相互作用"）
    ↓
ChromaDB 向量检索 Top-4 相关药品说明书
    ↓
把说明书段落塞进 Prompt 上下文
    ↓
DeepSeek 总结风险等级 + 建议
    ↓
返回结构化 JSON
```

## 完整 Prompt

### 系统提示（System）
```
你是资深临床药师，擅长分析药物相互作用。
请严格根据提供的药品说明书摘要回答，不支持用其他数据。
回答时先引用说明书中的具体证据再下结论。
```

### 用户提示（User）
```
以下是数据库中与「华法林钠片、阿司匹林肠溶片」相关的药品说明书摘要：

### 华法林钠片
【华法林钠片】规格 3mg*100片。用法：口服，每日1次，固定时间服用……
注意：与阿司匹林、布洛芬等非甾体抗炎药合用增加出血风险……

### 阿司匹林肠溶片
【阿司匹林肠溶片】规格 100mg*30片。用法：口服，每次1片，每日1次……
禁忌：活动性消化道溃疡患者；出血体质……
注意：与华法林合用显著增加出血风险……

### 硝苯地平控释片
【硝苯地平控释片】规格 30mg*7片……

### 辛伐他汀片
【辛伐他汀片】规格 20mg*7片……

---

请基于以上摘要分析用户当前用药清单（华法林钠片, 阿司匹林肠溶片）是否存在相互作用风险。
若数据库中无直接证据，请诚实告知并基于药理学常识给出推测。

**严格 JSON 格式** 返回（不要任何多余文字、不要 markdown 代码块）：

{
  "has_risk": true/false,
  "risks": [
    {
      "pair": ["药品A", "药品B"],
      "level": "critical|major|moderate|minor",

      "description": "作用机制简述",
      "suggestion": "建议措施"
    }
  ],
  "summary": "整体概述，1-2 句话"
}
```

## 设计要点

1. **RAG 而非纯 LLM**：避免 DeepSeek 编造药品说明书内容
2. **Top-4 检索**：覆盖多药情况，避免漏掉关键相互作用
3. **JSON 模式 + 4 级风险**：便于前端按颜色渲染卡片
4. **中文标签 `level_cn`**：方便前端展示

## 4 级风险等级（前端配色）

| Level | 中文 | 颜色 | 含义 |
|---|---|---|---|
| critical | 严禁 | 🔴 红 | 必须医生评估 |
| major | 较严重 | 🟠 橙 | 需医生关注 |
| moderate | 中等 | 🟡 黄 | 留意观察 |
| minor | 轻微 | 🟢 绿 | 一般无碍 |
