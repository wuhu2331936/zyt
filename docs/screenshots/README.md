# 截图说明（演示视频 + README 用）

> 本目录的截图用于：
> 1. README.md 功能演示区
> 2. 演示视频嵌入缩略图
> 3. 评委快速了解产品

## 截图规范

| 项 | 标准 |
|---|---|
| 分辨率 | 540 × 960（移动端 iPhone 12） |
| 格式 | PNG（无损）/ JPG（< 200KB） |
| 边框 | 圆角 24px + 阴影（iOS 风格） |
| 标的状态栏 | 必须显示真实时间 + 信号 |
| Demo 数据 | 用真实场景，不要用「xxx 文本测试」 |
