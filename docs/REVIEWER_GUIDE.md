> 三种方式任选其一。**方式一最省事**（点链接即可，无需安装任何东西）。

## 方式一：在线访问（推荐）

打开本项目已部署的公网网址：

<https://zhiyaotong-330314-11-1509077553.sh.run.tcloudbase.com>

手机、电脑浏览器均可。建议用手机体验完整交互（本项目为移动端优先设计），
评审若需语音输入，建议使用 **Chrome 或 Edge 浏览器**（见文末常见问题）。

- 手机上打开后，可通过浏览器菜单「添加到主屏幕」获得类 App 的体验
- 首次访问若出现云服务商的「页面访问提示」页，点击**「确定访问」**即可进入应用
- 若页面样式异常，请按 `Ctrl + F5` 强制刷新（应用已内置缓存自毁机制）

## 方式二：本地一键启动（无需任何 API Key）

适用于没有在线地址、或希望离线评审的情况。

### 前置条件

- 已安装 **Python 3.10 及以上**（[下载地址](https://www.python.org/downloads/)）
- 无需 Node.js（前端构建产物已随源码提供在 `frontend/dist`）
- **无需申请任何 API Key** —— 未配置密钥时程序自动进入演示模式

### Windows 操作步骤

1. 解压作品压缩包
2. 双击根目录下的 **`启动（评审用）.bat`**
3. 脚本会自动完成：创建虚拟环境 → 安装依赖 → 启动服务 → 打开浏览器
4. 首次运行需联网下载依赖，约 3–5 分钟，请耐心等待
5. 看到 `Uvicorn running on http://127.0.0.1:8000` 即启动成功

### macOS / Linux 操作步骤

```bash
cd zhijiayaotong/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements-cloud.txt
uvicorn app.main:app --port 8000
```

然后浏览器打开 <http://localhost:8000>

## 关于「演示模式」

本项目核心功能依赖两个云端大模型：

| 功能 | 依赖服务 | 所需环境变量 |
|---|---|---|
| 拍照识药 | 阿里云百炼 Qwen3-VL | `DASHSCOPE_API_KEY` |
| 用药问答 / 相互作用检查 | DeepSeek | `DEEPSEEK_API_KEY` |

**为方便评审，程序内置了演示模式：**

- 触发条件：未配置对应 API Key，或显式设置 `DEMO_MODE=1`
- 表现：页面顶部出现橙色「演示」提示条；此时
  - **拍照识药**返回预置的常用药信息（苯磺酸氨氯地平片 / 阿托伐他汀钙片 / 阿司匹林肠溶片轮流展示）
  - **用药问答**按关键词返回预置的药师口吻回答
  - **相互作用检查**按内置的 4 条用药规则匹配风险（含阿司匹林+布洛芬、他汀+大环内酯类等经典案例）
- 目的：保证评审老师在**没有任何密钥、没有网络**的情况下，也能完整走通全部交互流程

> 演示数据仅用于流程展示，不代表真实模型输出。配置真实 Key 后提示条自动消失，
> 全部功能切换为真实 AI 调用。真实调用若失败（如账户余额不足），也会自动降级为演示数据，
> 保证界面不会白屏或报错。

## 功能清单与体验路径

| 模块 | 入口 | 操作 |
|---|---|---|
| 首页 | 底部「首页」 | 查看今日用药概览、待服用 / 已服用统计 |
| 拍照识药 | 底部「识药」 | 点击虚线区域上传药盒照片 → 自动识别药品名 / 规格 / 用法 |
| 用药问答 | 底部「问答」 | 输入或语音提问（如「这个药怎么吃」）→ 药师口吻回答，可语音播报 |
| 用药提醒 | 底部「提醒」 | 新增服药提醒、查看今日清单、标记已服用 |
| 相互作用检查 | 首页 → 药品清单 ≥2 种 | 自动分析组合风险并给出建议（含 4 条内置规则演示） |
| 语音播报 | 问答页 | 回答下方点击播放，使用 Edge-TTS 合成中文语音；服务端不可用时自动改用浏览器语音 |

> 语音输入（麦克风说话提问）依赖浏览器原生 **Web Speech API**，
> 目前仅 **Chrome / Edge / Safari** 支持；微信内置浏览器、QQ 浏览器、UC 浏览器不支持。
> 不支持时页面会隐藏麦克风按钮并提示改用手写输入，**不影响问答、识药等其他所有功能**。

## 常见问题

**Q：打开是白屏 / 没样式？**
浏览器缓存了旧版本。请按 `Ctrl + F5` 强制刷新，或用无痕窗口打开。

**Q：提示「无法访问此网站」？**
服务未启动。请确认启动脚本的黑窗口仍然开着，关闭它服务就停了。

**Q：手机打不开？**
本地启动的服务仅限本机访问。手机请使用**方式一**的公网地址。

**Q：识别结果是假的？**
页面顶部有橙色「演示」条时，说明运行在演示模式（未配置 Key）。配置 Key 后即为真实识别。

**Q：点击麦克风没反应 / 看不到麦克风按钮？**
语音输入依赖浏览器原生的 Web Speech API，仅 Chrome / Edge / Safari 支持；
微信内置浏览器、QQ 浏览器、UC 浏览器不支持。这是浏览器能力限制，不是程序缺陷。
不支持时按钮会自动隐藏并提示改用文字输入，其余功能（拍照识药、问答、相互作用、提醒）均不受影响。
如需体验语音输入，请用 **Chrome / Edge 最新版** 打开，并在弹窗中允许麦克风权限（需 HTTPS 页面）。
